# 已读状态与回执设置

已确认的自己发送的消息显示“已发送”或“已读”；失败与发送中沿用原待发送操作。旧接口、原型数据和收到的消息不伪造发送状态。

私信设置提供全局回执开关；会话更多菜单提供本会话开关。总开关关闭优先，任意一方关闭时双方均不显示已读。私下阅读不在重新开启后补发，内部未读数仍正常维护。

打开新会话时先校对有效策略，关闭隐私时立即隐藏缓存，迟到的旧响应不能重新公开状态。另一设备重新开启自己的总开关时也会更新本地策略，再校对历史回执。只读回执校对覆盖已加载历史，不把历史定位变成标读。弹层遮挡、上翻历史和后台页面也不自动标读；滚回底部可及时确认已看到的快照。
