# 私信引用回复与设置

消息操作菜单新增引用回复，并保留撤回、举报。引用上方展示原消息摘要，点击进入历史定位；撤回或不可访问的引用显示占位。输入栏可取消引用，只有引用的草稿也能刷新恢复。

发送失败后，待发送库保留原消息ID和提交键，不复制引用原文。重试沿用同键；无效引用可移除并另存，保留正文、更换提交键。异步保存期间选择的新引用不会被旧发送结果清除。

私信列表新增“私信设置”：允许一条文字请求、仅互关或已购联系、不接收新私信。已有已接受会话不变，服务器负责准入。列表和会话切换会同步辅助入口，分页按钮不会在重画时重复。

保留既有字体、气泡、输入栏手势和导航结构；引用、消息菜单、取消和待发送操作目标至少44px，支持手机、iPad、电脑和深浅色。静态缓存更新为ctrlz-static-v21，communication资源更新为20261110-r9。

这批前端需要配套的后端reply字段、交流设置接口及0040迁移。没有推送或部署。验证命令为 `node --test test/*.test.cjs tests/*.mjs`，新浏览器脚本为tests/dm-replies*.js。验证记录与截图位于 `D:/ctrlz/output/communication-dm-replies-20261110`。
